Fonts bundled with AspirantOS (so the app looks the same without internet)

File                                     Family          Used for                          Licence file
fraunces-latin-wght-normal.woff2         Fraunces        display headings, ticket headline  OFL-Fraunces.txt
manrope-latin-wght-normal.woff2          Manrope         UI and body text                   OFL-Manrope.txt

Source: Fontsource variable packages, version 5.3.0, downloaded on 26-Oct-2026 from
https://cdn.jsdelivr.net/npm/@fontsource-variable/<family>@5.3.0/files/
Each file is a variable font (one file covers every weight) with the Latin character set.
All three fonts are licensed under the SIL Open Font License 1.1, which allows bundling them
with an application; the licence files must stay next to the fonts.
The @font-face rules are in assets/css/tokens.css.
